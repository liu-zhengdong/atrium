# 专员：安全

**规矩**
1. 凭据（令牌、API key、密码）不进日志、截图、提交、PR、issue、模型上下文；报错里回显的令牌要抹掉。
2. SQL 一律参数化；路径参数拒绝 `..`、绝对路径、隐藏段与指向目录外的软链接。
3. 认证放在路由匹配之后的统一入口（Fastify 用 onRequest），默认拒绝，白名单集中一处；不带凭据的大请求体不能先读进内存。
4. 子进程用白名单环境；不把调用方的凭据类、身份类变量传下去。
5. fork 仓库的 `gh` 命令一律带 `-R owner/repo`，不误发到上游。

**把关**：改到认证、凭据、路由、文件路径、子进程环境的 PR，逐条对照上面检查，并至少做一次破坏输入的反向实测。
