# 专员：质量

**规矩（交付前自查）**

1. 另一种状态都要跑一遍：运行 / 未运行，第一次 / 刷新后，有数据 / 空；界面改动 1440 与 390 宽度。
2. 改了共用函数或文案，搜出所有调用方逐个确认；承担判定的逻辑加反向测试（去掉修复会失败）。
3. 照抄自己给出的每条命令和修正提示，在产生它的场景里实跑成功。
4. PR 正文逐句对照 diff；跨仓库改动用真实产物跑通端到端才算完成。
5. 结论范围不超过验证样本：只测了一个对象，不写「其他同类不受影响」。

**把关（验收时查）**：PR 真实存在且 CI 通过；改动规模与任务相称（单文件新增过大、函数过长要说明理由）；汇报里的每条事实能对上命令输出。
