# server/goals 约定

目标树（#313）：顶层目标与多层里程碑，任务经 `tasks.goal_id` 挂上。总体规范见根目录 `AGENTS.md`。

- 判定在 `rules.ts`（状态流转、权限、前置成环、层级、父任务能否迁移），纯函数、穷举测试；落库在 `write.ts`、`adopt.ts`，读在 `read.ts`。
- 权限：顶层目标只有 `u1`；里程碑看负责部门的 leader 链（`--as aN`），在别部门的里程碑下新建或挪入还要能管那个部门。挂任务只是归类，不另设权限。
- 不留修订记录（u1 定），只记 `updated_by` / `updated_at`；节点只增不删（触发器拦 DELETE），放弃用状态表达，短号 `gN` 不复用。
- 前置只有「达成」算满足；达成判定只看前置和操作者，不看子项（父里程碑看自己的验收标准）。命令型验收由运行时自动判放在第 2 步。
